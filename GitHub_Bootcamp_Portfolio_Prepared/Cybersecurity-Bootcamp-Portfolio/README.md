# Cybersecurity Bootcamp & Python Portfolio

Educational work covering Python programming, command-line utilities, foundational cybersecurity concepts and operations-related automation. This repository contains **learning projects**, not production-ready security tools.

## Projects

| Folder | Highlights |
| --- | --- |
| `01-python-capstones` | Task manager, inventory system, OOP capstone, calculator |
| `02-linux-cli-tools` | Python implementations of `cat`, `echo`, and `grep` |
| `03-security-learning` | Cipher exercise and written security-awareness exercises |
| `04-python-practice` | Programming fundamentals, file handling, loops, functions and classes |
| `05-needs-review` | Original submissions with known syntax errors; not ready to run |

## How to run

Requires Python 3. Run a script from its folder, for example:

```bash
python 04-python-practice/minesweeper.py
```

Some scripts require interactive input or companion text files. Review their code before execution.

## Security and limitations

- `task_manager_capstone.py` uses plaintext credentials and creates a default `admin;password` account. **Do not use it for real accounts or sensitive data.**
- `05-needs-review/email.py` and `05-needs-review/optional_challenge.py` have syntax errors in the original submissions.
- This package was checked for Python syntax, but was **not functionally tested end to end**.
- No Wazuh, Metasploitable, Apache TLS, or cloud lab artifacts were present in the uploaded ZIP, so none are claimed as included.
- Do not commit real credentials, personal data, or confidential lab reports.
